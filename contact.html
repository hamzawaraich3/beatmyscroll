Bug reports and feedback

The simplest way to reach the project right now is through the public BeatMyScroll GitHub issue tracker. Use it for broken gameplay, device compatibility problems, audio issues, leaderboard problems or feature ideas.

Please avoid posting passwords, private account information or other sensitive personal data in a public issue.

OPEN GITHUB ISSUES →

What helps when reporting a bug

Include the device type, browser, what you expected to happen and what actually happened. For performance problems, mentioning whether the issue occurred during normal play, hyperspace or Aura Mode is useful.

Advertising and privacy

For information about advertising, cookies, browser storage and leaderboard data, see the Privacy Policy. Advertising is kept outside active gameplay and the game-over screen.
