THREE DIFFERENT SKILLS

Raw score

Raw score is the broadest measure of a run. It combines scroll input with the game's speed multiplier and any active RUSH multiplier. A huge score normally requires both pace and survival rather than one isolated burst.

Average speed

Average speed rewards sustained intensity. The game totals normalized scroll input across the active portion of the run and divides it by active time. Brief spikes matter less here than staying fast.

Maximum speed

Maximum speed is the opposite: it preserves the highest instantaneous scroll-rate burst the game observed. It is intentionally separate from average speed so one extreme flick cannot masquerade as sustained pace.
